# 반복학습 (웹앱)

망각곡선에 맞춰 복습할 날을 알려 주는 반복학습 앱입니다. 아이폰·안드로이드 모두 인터넷 주소로 열고, 로그인 없이 각 휴대폰 안에만 저장됩니다.

- 공부한 것(제목, 과목, 공부한 날, 메모)을 등록하면 1·3·7·14·30일 뒤 복습 일정을 자동으로 잡음 (간격 변경 가능)
- 늦게 복습하면 실제로 복습한 날부터 다음 간격을 셈. "헷갈려요"는 같은 차례를 내일 한 번 더
- 학습계획 탭: 공부할 날을 정해 두고(여러 날로 나눠 한 번에 등록 가능), 그날 "공부 완료"를 누르면 복습 일정이 자동으로 잡힘. "내일로 미루기" 가능
- 오늘 복습할 것, 다가오는 7일, 과목별 전체 목록, 연속 복습 일수
- 휴대폰 캘린더 알림 등록(.ics), 백업 저장·불러오기, 홈 화면 추가, 오프라인 실행

## 파일
- `index.html`: 앱 전체
- `sw.js`: 오프라인용 서비스 워커. 앱을 고치면 `VERSION`을 올려야 휴대폰에 새 버전이 퍼짐
- `manifest.webmanifest`, `icons/`: 홈 화면 아이콘
- `gowun-batang-bold.woff2`: 고운바탕 글꼴 (SIL Open Font License), 한글 2,350자 서브셋
